1. **Kenapa beberapa transaksi rinciannya tidak masuk di laporan buku pembantu? Hanya ada globalannya**&#x20;

2. **Kapan User perlu minta approval untuk bisa akses pada bumi soft**&#x20;

3. **Kenapa waktu import tidak berhasil?**&#x20;

4. **Tgl kasbon tdk boleh lebih awal dari perintah bayar**
